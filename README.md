# Klyde Vrene — edukacyjny TikTok

Film o świadomym wprowadzaniu kosmetyków: 1080 × 1920, 30 FPS, 40 sekund, oryginalna polska narracja ElevenLabs.

## Otwórz film

1. Otwórz [film z napisami](film/Klyde-Vrene-TikTok.mp4).
2. Na stronie pliku kliknij **Download raw file** (ikona pobierania). Jeśli GitHub pokazuje odtwarzacz, możesz też odtworzyć film bezpośrednio.
3. Otwórz pobrany MP4 w przeglądarce, galerii telefonu, VLC lub systemowym odtwarzaczu. Napisy i podświetlenia są już w obrazie — nie trzeba wczytywać SRT.
